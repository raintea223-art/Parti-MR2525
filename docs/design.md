# Edgeware X 设计规范（Design Spec）

> 依据：edgewarex.com（Framer 构建）原始 CSS，2026-10-30 抓取并逐项提炼（第二版：纠正配色定性）。  
> 用途：Parti 模板库前端重构的**设计基准**。落地前先读本文件，再动手。

---

## 0. 一句话气质

**深色原生（dark-first）· 超大标题 · 负字距 · 大留白 · 数字强调 · 玫红点缀 + 品红霓虹光晕。**

官网不是"浅色底 + 蓝色点缀"的普通科技站，而是**以纯黑为底、白色为字、玫红（品红）为品牌点缀、蓝色仅为链接功能色**的深色科技风。

### ⚠️ 第二版关键纠正（上一版的定性搞反了）

上一版把"蓝色 #0099ff"写成「全站最核心品牌色」。重新逐条拆解 CSS 后确认：

| 判断 | 上版（错） | 本版（对） |
| --- | --- | --- |
| 品牌点缀色 | 蓝色 #0099ff | **玫红 #ff008c** |
| 蓝色 #0099ff 的真相 | 品牌主色 | **Framer 框架默认链接色**（156 次全是 `--framer-link-text-color`），非品牌决策 |
| 官网自定义品牌色 | 蓝 | 自定义 token `#ff008c`（玫红，15 次引用）；品牌蓝 `#1c8eff` 只定义 1 次、几乎没用 |
| 装饰/氛围 | 蓝+品红 | **全部紫→品红系**，无蓝色参与 |

结论：**视觉上官网大量出现的是玫红/品红**（文字高亮、实心背景、边框、NEW 徽章、霓虹光晕、装饰渐变），蓝色只是正文链接的默认色，面积小、不抢眼。

## 1. 配色 Token

| 角色 | 色值 | 说明 |
| --- | --- | --- |
| **品牌点缀色 / 强调（主）** | `#ff008c`（rgb 255,0,140） | **官网自定义品牌色**。用于文字高亮、实心背景填充、边框、"NEW" 徽章；CSS 里作为 `--token-19cef87f…` 定义，引用 15 次 |
| **霓虹光晕（品红）** | `#f81fff`（rgb 248,31,255） | `text-shadow: 0 0 5px #f81fff`（双层），文字霓虹发光，视觉最抢眼 |
| **装饰渐变（紫→品红）** | `#ff0084 → #c96ef0 → #a45cdb → #fa004f` | 141deg 渐变，用于图形 / logo 装饰；另有 229deg 灰版 |
| **链接功能色（非品牌）** | `#0099ff`（rgb 0,153,255） | Framer 框架默认 `--framer-link-text-color`，仅链接文字；**非品牌色，落地可保留为链接色或统一为玫红** |
| **品牌蓝（定义未用）** | `#1c8eff` | 官网自定义 token，但几乎未使用，可忽略 |
| **深色背景（主）** | `#000000` | 页面主体背景，纯黑 |
| **深色表面（次）** | `#0d0d0d` | 深黑，hero 过渡、卡片 |
| **浅色背景（辅）** | `#ffffff` | 少数浅色 section |
| **深色区正文** | `#ffffff` | 白字（黑底上） |
| **浅色区正文** | `#222222`（rgb 34,34,34） | 冷黑字（白底上） |
| **深色区边框** | `rgba(255,255,255,0.10)` | 白 10% 透明，分隔线 |
| **深色区表面/卡片** | `rgba(255,255,255,0.05)` | 白 5% 透明，卡片/悬浮面 |
| **浅色区边框** | `#222222` | 硬黑边（官网浅色区用 `1px solid rgb(34,34,34)`） |

### 关键原则

1. **深色是默认**，不是"深色模式"。白底是少数区。
2. **玫红 #ff008c 是品牌点缀/强调色**：用于可交互强调、文字高亮、实心填充、边框、徽章、光晕。
3. **品红只做"氛围 / 光晕 / 装饰"，不用于大面积正文底色**——大面积底色仍是黑/深黑。
4. **蓝色 #0099ff 只是链接默认色**：可保留作链接色（可读性好），但它不是品牌表达；若追求品牌统一，链接也可用玫红或白。
5. 层次靠**透明度**（白 5% / 10%）而不是浅灰 HEX——这是深色 UI 的正统做法。

## 2. 字体与排版

### 2.1 字体

| 场景 | 字体 |
| --- | --- |
| 拉丁/数字 | **Figtree**（几何无衬线，Variable，500 / 700 两档为主） |
| 辅助正文 | **Inter**（Medium） |
| 中文（适配） | 思源黑体 / PingFang SC / HarmonyOS Sans SC（几何无衬线，与 Figtree 气质一致） |
| 技术标注/编号 | 官网**未使用**等宽字体，统一 Figtree 即可（上一次误加 Fragment Mono，需移除） |

### 2.2 字号阶梯（官网实测值）

```
12  14  15  16  18  21  23  28  30  32  35  40  45  50  56  70  115 px
```

| 层级 | 字号 | 用途 |
| --- | --- | --- |
| Hero 主标题 | **115px** | 首屏一句话（如 "Editable Spatial System"） |
| 大 Section 标题 | 56–70px | 章节标题 |
| 中标题 | 32–45px | 卡片/模块标题 |
| 数字强调 | 超大（可到 115px） | "1,000 Cycles!"、"8 N·m"、"1/40" |
| 正文 | 16–18px | 段落 |
| 辅助/标签 | 12–14px | 注释、编号、眉题 |

### 2.3 字距（负字距是品牌特征）

| 场景 | letter-spacing |
| --- | --- |
| 最大标题 | `-0.06em` |
| 大标题 | `-0.04em` |
| 标题/正文标题 | `-0.03em` ~ `-0.02em` |
| 正文 | `0` ~ `-0.01em` |

### 2.4 行高（紧凑）

| 场景 | line-height |
| --- | --- |
| 超大/大标题 | `1em` ~ `1.1em` |
| 标题 | `1.2em` |
| 正文 | `1.4em` ~ `1.5em` |

## 3. 形状与边界

### 3.1 圆角

| 元素 | 圆角 |
| --- | --- |
| 区块 / 卡片主体 | **0px（直角）** 为主 |
| 图片 / 中等卡片 | 12–18px |
| 按钮 / pill | **40px（胶囊）** 或更大（363px 全胶囊） |

> 官网是"锐利区块 + 胶囊按钮"的组合，**不是**"到处大圆角"。

### 3.2 边框

- 深色区：`1px solid rgba(255,255,255,0.10)`
- 浅色区：`1px solid #222222`（硬边，官网明显偏好硬边而非阴影）

### 3.3 阴影

官网**几乎不用投影**，层次靠背景色 + 边框区分。落地时避免 `box-shadow` 堆叠，用透明面 + 细边框。

---

## 4. 装饰元素（氛围）

### 4.1 品红径向光晕

```
radial-gradient(50% 50% at 50% 3.4%, rgba(255,0,140,0.19) 0%, transparent 100%)
```

位置在区块顶部居中，向下淡出。用于 hero / 深色区的氛围。

### 4.2 品红→黑 过渡渐变

```
linear-gradient(149deg, rgba(255,0,140,0.19) 0%, rgba(13,13,13,0.8) 29%~74%, rgba(255,0,140,0.21) 100%)
```

用于深色 section 的边界过渡。

### 4.3 紫→品红装饰渐变（logo/图形）

```
linear-gradient(141deg, #ff0084 13%, #c96ef0 35%, #a45cdb 64%, #fa004f 88%)
```

### 4.4 品红霓虹光晕（文字）

```
text-shadow: 0px 0px 5px rgb(248, 31, 255), 0px 0px 5px rgb(248, 31, 255);
```

用于强调文字 / 标题的霓虹发光，是官网最抢眼的视觉元素之一。

## 5. 组件规范（落地映射）

### 5.1 按钮

| 类型 | 样式 |
| --- | --- |
| 主按钮 | **玫红 `#ff008c` 填充**，白字，胶囊 40px，无阴影（官网用玫红做实心填充 + 边框 + 徽章） |
| 次按钮 | 白 5% 表面 + 白 10% 边框，白字（深色区）；黑字（浅色区） |
| 文本/链接 | 蓝 `#0099ff`（框架默认，可读性好；若要品牌统一可换玫红） |

### 5.2 卡片

- 深色区：`background: rgba(255,255,255,0.05)` + `border: 1px solid rgba(255,255,255,0.10)`，直角或 12–18px
- 浅色区：`background: #fff` + `border: 1px solid #222`

### 5.3 导航

- 深色导航：黑底 + 白字，当前项/高亮用玫红 `#ff008c`
- logo 位放品牌字标，链接用蓝或玫红

### 5.4 数字强调

价格、工时、周期等关键数字，用**超大字号 + 负字距 + Figtree** 单独强调（呼应官网 "1,000 Cycles!"）；如需发光，可叠品红霓虹 text-shadow。

### 5.5 标签/徽章

- 状态徽章（已发布/草稿等）用**描边 + 透明底**，不用高饱和填充块。
- 关键强调徽章（如 "NEW"）用**玫红实心填充**（官网 `data-framer-name="new"` 即玫红底）。
- 编号（`TPL-SHW-001`）用 Figtree，字号偏小、负字距。

## 6. 落地到模板库的关键差距（上次踩的坑）

| 维度 | 上次做法（错） | 本规范（对） |
| --- | --- | --- |
| 底色 | 浅色冷灰 `#f6f7f9` | **纯黑 / 深黑** |
| 正文色 | 冷黑 `#222`（浅底） | **白 `#fff`（黑底）** |
| 点缀色 | 蓝色为主 | **玫红 `#ff008c` 为主点缀**（蓝色仅链接） |
| 圆角 | 整体加大 | **直角为主 + 胶囊按钮** |
| 字体 | Figtree + Fragment Mono | **仅 Figtree（+ 中文黑体）** |
| 层次 | 阴影 | **透明面 + 细边框** |
| 标题 | 未做超大标题 | **超大标题 + 负字距 + 紧凑行高** |
| 光晕 | 蓝+品红双光晕（方向对） | **品红顶部径向光晕 + 品红霓虹文字** |

---

## 7. 落地优先级（建议）

1. **底色先翻黑**：`:root` 背景从浅灰改纯黑/深黑，正文白字——这是观感差距最大的单项。
2. **点缀色换玫红**：把主交互/强调色从蓝 `#0099ff` 改为玫红 `#ff008c`（`--accent`），蓝色降为链接色或 `--link` 单独变量。
3. **字体收敛**：去掉 Fragment Mono，标题字重 700、负字距 `-0.03~-0.04em`、行高 `1.1em`。
4. **按钮改胶囊玫红填充**：40px 圆角，玫红底白字。
5. **卡片改透明面**：`rgba(255,255,255,0.05)` + 白 10% 细边框。
6. **光晕定位**：品红径向光晕放区块顶部居中，向下淡出；关键标题可加品红霓虹 text-shadow。
7. **数字强调**：价格/工时等核心数字用 Figtree 大字号突出。

> 注：模板库是"后台管理 + 对外展示"双门面工具，深色后台可直接套用；对外展示页（模板图册）建议复用同一套 token，但可保留纯黑 hero + 超大标题的首屏，与官网一致。
