# MR2525 方案模板库

团队协作用的 **模板录入 · 自动编号 · BOM 报价 · 工作流** 系统。适合约 100 个手工 SketchUp 方案（含面板）的统一管理；前期可本地/局域网共用，并 **导出 CSV 同步到飞书多维表格**。

## 快速启动

```powershell
cd "c:\Users\zl450\Nutstore\1\我的坚果云\Cursor\mr2525-template-catalog"
npm install
npm start
```

浏览器打开：**http://localhost:3847**

默认管理员：`admin` / `admin123456`（首次建库；若已改过密码以实际为准。登录后请在「用户管理」修改。）

> 需要 **Node.js 18+**（推荐 22）。首次运行可能出现 `ExperimentalWarning: SQLite` 提示，可忽略。

**修改后端代码后请重启服务**（若端口占用先释放再启动）：

```powershell
Get-NetTCPConnection -LocalPort 3847 -State Listen -ErrorAction SilentlyContinue |
  ForEach-Object { Stop-Process -Id $_.OwningProcess -Force -ErrorAction SilentlyContinue }
cd "c:\Users\zl450\Nutstore\1\我的坚果云\Cursor\mr2525-template-catalog"

```

启动成功时应看到 `场景手册 PDF: 20260603-handbook-design-system`。手册品牌页编辑见 [手册编辑指南](docs/HANDBOOK-EDITING.md)。前端改动请 **Ctrl+F5**，当前侧栏 UI 版本为 **20261102a**。

## 功能概览

| 模块 | 说明 |
|------|------|
| **新建模板** | 上传 skp、按判归 10 条选择场景 → 自动生成 `TPL-场景-序号` 与 slug |
| **模板列表** | 筛选、搜索、**多标签交集**、序号/封面、表头排序、进入详情协作 |
| **详情页** | 基本信息、BOM、内部参考价、八类件交付附件、整包价与发布信息、**版本历史**、**外包深化表单**、状态推进 |
| **单价库** | 型材/六通/五金/板材/供应商/非标；六通·五金可附图片 |
| **模板图册** | 已发布方案合成展示图，显示整包价含税与基准日，下载 PNG / PDF 方案手册 |
| **场景库** | 可配置场景、效果图/渲染图、图上标记关联已发布模板、场景手册 PDF |
| **标签库** | 字云浏览全部标签；详情用 `#` 打标（可新建）；按标签筛模板列表 |
| **导出 CSV** | 导入飞书多维表格（主表 + BOM） |

## 协作流程

```
录入员 上传 skp 登记 → 待清单深化
录入员 补齐八类件/尺寸/BOM/整包价/基准日/工时/交付清单 → 系统校验 → 待审核
审核员 发布前复核 + 核对 checklist → 已发布 → 模板图册 / 飞书同步
```

状态只能按流程推进，避免跳步。上架与交付使用同一套八类件准入标准，提交审核与审核发布均由服务端校验。审核可退回至「待清单深化」；已下架须重新上架再审核。

**已发布：** 除 **标签** 外不可改；须 **下架** 后编辑，再审核上架（版本 +0.1；换 skp 模型 +1）。详情状态栏按钮为 **下架**。

**上手指南与流程图：** 侧栏 **流程说明**，或仓库 [docs/WORKFLOW.md](docs/WORKFLOW.md)。**2026-05-31 升级摘要：** [docs/UPGRADE-20260531.md](docs/UPGRADE-20260531.md)。

## 自动编号规则

格式：**`TPL-{场景代码}-{3位顺序号}`**

- **场景代码**：见下表（如展厅 `SHW`）
- **顺序号**：同一场景下全局递增（001、002…），与旧编号共用计数
- **模板名称**：独立取自 skp 文件名，不进入模板编号

| 场景 | 代码 | 示例编号 |
|------|------|----------|
| 展厅 | SHW | TPL-SHW-001 |
| 零售 | RET | TPL-RET-001 |
| 活动 | EVT | TPL-EVT-001 |
| 办公 | OFF | TPL-OFF-001 |
| 会展 | EXH | TPL-EXH-001 |
| 宠物 | PET | TPL-PET-001 |
| 市集 | MKT | TPL-MKT-001 |
| 轻餐饮 | FNB | TPL-FNB-001 |
| 公园商业 | PRK | TPL-PRK-001 |
| 其他 | OTH | TPL-OTH-001 |

新建页场景选择区显示判归 10 条，按顺序判定，命中即停；全部不成立时归「其他」。slug 示例：`zhanting-001`。

## 内部参考价计算（对齐《海智详细清单》）

### MR2525 型材
- 出厂参考价 = `ROUNDUP(长度(in) × 1.778 + 42, 0)`（由单价库公式参数计算；**颜色不影响单价**）
- 报价单价 = 出厂价 × 系数（默认 1）
- 小计 = 数量 × 报价单价
- **颜色**：银色 / 木色等，由管理员在单价库 · 型材 Tab 维护；清单中标注用

### 五金配件
- 从配件目录选取（六通、CoreLOX 连接件、地脚、灯带等）
- 小计 = 数量 × 出厂单价

### 板材
- 面积(㎡) = 长(mm) × 宽(mm) / 10⁶，边长由 inch × 25.4 换算
- 按㎡计价：件单价 = 面积 × ㎡单价；固定件价：直接填件单价
- 小计 = 数量 × 件单价
- **同一模板可添加多种板材**（不同材质/厚度可多行）
- **单价库**：同色厚同价的多色合并为一条价库条目；模板每行选标配颜色（见 [PRICE-LIB §17](docs/PRICE-LIB-UPDATES.md#17-2026-06-04--板材一条目多色)）

### 单价库（管理员维护）

侧边栏 **单价库** 含：**型材公式与型材颜色**、六通、五金配件、板材、**供应商库**、非标件。同事在模板详情中只能**选取**，不能改价。详见 [单价库微调说明](docs/PRICE-LIB-UPDATES.md)。

| 分类 | 维护要点 |
|------|----------|
| **六通** | 名称、型号、对内/对外价；**可选图片**；序号展示 |
| **五金配件** | 名称、规格、单位、链接、**供应商（必填）**、对内/对外价；**可选图片** |
| **板材** | 材质、厚度、计价、供应商；**一条目多色**（RGB / **透明**）；CSV（支持分号多色）；合并重复条目 |
| **供应商库** | 从五金/板材汇总供应商名；维护联系人、电话、备注 |
| **非标件** | 类别、项目、对内/对外价、备注；与模板「其他」Tab 同步 |

板材颜色支持 **透明**（color_hex=transparent）。改价后同步单价与规格字段，**不覆盖** BOM 行已选颜色。五金/板材改价后，已引用模板的报价行自动同步。

### 参考价区间与对外整包价

内部参考价由 BOM 与单价库计算，用于成本核对、内部列表与算价过程。可定制开启时，区间仅来自同材质、同厚度下的皮肤色差；不再使用「下限 × 1.15」。

客户侧图册、方案手册、报价单与合同使用 **整包价含税 + 价格基准日**，不直接对外展示内部参考价区间。安装工时只登记 **n 人·h 总量**。

### 详情 · 基本信息栏

| 分组 | 说明 |
|------|------|
| 标识 | 名称、负责人、版本（三列） |
| 尺寸 | 宽 / 深 / 高 mm（三列） |
| 文案 | 一句话卖点、报价口径 |
| 价格 | 内部参考价上下限；**可定制**（`skin_upgrade_enabled`，chip 复选框） |
| 封面 | 缩略图下拉选择实拍/效果图/渲染图来源，选中即保存 |
| 交付与发布 | 整包价含税、价格基准日、安装工时、交付文件清单、EFF/RND 合并留痕 |
| 交付附件 | DWG / PDF / BOM / MAN / INF，上传、列表、删除；已发布只读 |
| 历史 | 旧模板若有 `panel_note`，详情只读展示；新模板不再编辑该字段 |

表单已移除：**皮肤选配说明**编辑、**询单表单链接**。详见 [详情基本信息栏说明](docs/DETAIL-BASIC-INFO-UPDATES.md)。

## 数据存储

- 数据库：`data/catalog.db`（SQLite，可备份）
- 附件：`data/uploads/{模板编号}/`（图片、SKP 与五类交付附件）
- 飞书导入模板：`data/feishu/*.csv`

2. 侧边栏 **导出主表 CSV / 导出 BOM CSV**  
3. 导入飞书多维表格（见 `docs/FEISHU-SETUP.md`）  
4. 对外画册展示整包价含税与价格基准日；内部参考价、成本、SKP 与 INF 不放入公开视图

## 八类件发布准入

八类件为 **EFF / RND / SKP / DWG / PDF / BOM / MAN / INF**。EFF/RND 至少一类；只有 EFF 时须勾选合并并填写交付备注。交付文件名采用 `模板号_类型码_[序号_]描述_vX.Y.扩展名`，交付文件清单填写文件名全称。整包价、基准日、安装工时、清单或实际附件任一不合规，均不能提交审核或发布。
